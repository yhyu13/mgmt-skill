# MGMT-SKILL.md 模板格式

> 管理方法论蒸馏项目的知识库文件格式
> 参考女娲SKILL.md，针对管理方法论做调整

---

## 文件命名

### 组织纵切

`[source-name]-[methodology].md`，例如：
- `huawei-dste.md`
- `netflix-culture.md`
- `pdl-profit-sharing.md`

### 个人蒸馏

`[person-name]-[methodology].md`，例如：
- `drucker-mbo.md`
- `welch-leadership.md`

### 学科横切

`[discipline]-[topic].md`，例如：
- `hr-recruitment.md`
- `marketing-growth.md`

## 与女娲SKILL.md的区别

| 维度 | 女娲SKILL.md（怎么想） | MGMT-SKILL.md（怎么做） |
|------|---------------------|---------------------|
| 蒸馏对象 | 思维模型 | 管理方法论 |
| 来源 | 个人 | 组织 + 个人 + 学科 |
| 核心产出 | 心智模型+决策启发式+表达DNA | 框架结构+关键模块+决策启发式 |
| 独有章节 | 表达DNA/反模式/智识谱系 | 与其他方法论的关系/实施检查清单 |
| 关系网络 | 人物间影响关系 | 方法论间上下游接口 |
| 横切模式 | 无 | 学科横切（前提条件矩阵+方法论对比） |
| 版权声明 | 无（个人思维不受版权保护） | 必须有（组织方法论有版权） |
