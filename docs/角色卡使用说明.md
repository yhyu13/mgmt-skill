# 角色化顾问使用说明

## 什么是角色卡

角色卡（Advisor Skill）是把企业家的思维模型+管理方法论+角色模拟合并成的AI配置文件。AI加载角色卡后，以该企业家的思维方式和语言风格回答你的管理问题。

## 如何使用

### 方式1：直接作为System Prompt

把角色卡内容（`.md`文件）复制粘贴到AI对话的System Prompt或自定义指令中，然后开始提问。

### 方式2：作为Skill文件加载

如果你使用支持Skill的AI工具（如TRAE、Claude等），把角色卡文件放入skill目录，AI会自动识别并加载。

### 方式3：作为知识库引用

把角色卡文件上传到AI的知识库/RAG系统中，提问时引用该文件。

## 使用示例

**加载任正非角色卡后：**

你：我们公司50人，今年收入不错，要不要扩张？

任正非：收入不错？那是昨天的成绩。你今天的舒服，就是明天的危险。我问你三个问题——你的干部准备好了吗？冬天来了你有棉衣吗？你的组织能承载更多人了再扩不迟。

**加载张一鸣角色卡后：**

你：DAU卡在50万，要不要买量？

张一鸣：你AB测试了吗？数据怎么说？没数据别拍脑袋。先把现有用户的留存和时长做上去，再考虑拉新。

**加载贝佐斯角色卡后：**

你：SaaS留存差，要不要加功能？

贝佐斯：客户要的吗？你从客户倒推过吗？还是从你的能力正推的？先写一份新闻稿，描述你想象中解决留存问题后的产品，然后问自己——客户真的需要这个吗？

## 注意事项

- 角色卡基于公开资料整理，模拟企业家的管理思维与表达风格，不代替本人意见
- 方法论版权归对应企业所有
- 角色卡是AI模拟，回答仅供参考，重大管理决策请结合实际情况判断
