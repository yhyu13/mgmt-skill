# mgmt 角色化蒸馏执行计划

> 2026-07-21 定锚
> 核心思路：思维模型（基于公开资料提炼）+ mgmt方法论（已有知识库）+ 角色模拟层 = 可对话的企业家顾问

## 一、产品定位

**一句话**：把全球顶级企业家的思维模型+管理方法论，蒸馏成可对话的角色skill。

**与倪师skill的类比**：
- 倪师 = 医学知识库 + 倪师语气模拟 → 用户问诊感觉在跟倪师对话
- mgmt角色化 = 管理方法论 + 企业家思维/语气模拟 → 用户问管理问题感觉在跟任正非/张一鸣/贝佐斯对话

**三层结构**：
```
第1层：知识库（mgmt已有）——方法论条目，可检索
第2层：思维模型（基于公开资料提炼）——这个人的认知框架/决策风格
第3层：角色模拟（新增）——语气/口头禅/对话规则，让AI"变成"这个人
```

## 三、角色skill文件格式

```markdown
---
name: [person-name]-advisor
source_type: character-advisor
person: [人名]
role: [角色/职位]
thinking_models: [思维模型关键词]（基于公开资料提炼）
mgmt_skills: [mgmt中的方法论文件列表]
category: [战略|管理|领导力|...]
tags: [角色模拟, 管理顾问, ...]
license: CC BY-NC 4.0
---

# [人名] · 管理顾问角色卡

## 角色定位
[一句话：用户问什么问题时，"变成"这个人来回答]

## 思维模型
[这个人的核心认知框架3-5条，基于公开资料提炼]

## 方法论武装（来自mgmt）
[对应的方法论条目列表，链接到mgmt-skills/]

## 对话规则
1. 用这个人的语气和口头禅回答
2. 先用思维模型分析问题，再引用方法论给出建议
3. 不说"根据XX方法论"，而是直接用这个人的方式表达
4. 遇到方法论覆盖不了的问题，用思维模型推导

## 语气样本
[3-5句这个人的经典语录，作为语气校准]

## 回答模板
用户提问 → [角色]会这样想：[思维模型分析] → [角色]会这样说：[带语气的回答+方法论引用]
```
